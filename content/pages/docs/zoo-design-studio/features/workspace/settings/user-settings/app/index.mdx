The `App` section contains the main user-level app preferences shown in the settings UI.

## Included Settings

### Theme

The overall appearance of the app.

### Show Debug Panel

Whether to show the debug panel, a development tool.

### Libraries

Project libraries control which project sources appear on Home.

On desktop, you can add, rename, reorder, and remove Local libraries. A Local library points
to a folder on your computer. Removing the library from settings does not delete the projects in that
folder.

Personal Cloud is a Cloud library backed by your Zoo account. Its files load into memory when
opened and save directly to Zoo; there is no local working-copy folder.

In the browser, projects use Personal Cloud. Local libraries are available only in the desktop
app.

For the full storage model, see
[Project Libraries](/docs/zoo-design-studio/features/data-management/project-libraries) and
[Cloud Storage](/docs/zoo-design-studio/features/data-management/cloud-sync).
