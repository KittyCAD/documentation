The Scene browser is being rolled out gradually. If it has not been enabled for your account,
use the existing Feature Tree and Bodies layout panes.

The Feature Tree shows the ordered operations used to build the current model in a
Scene browser tray docked to the side of the 3D scene. It fits its contents and scrolls when space is
limited, leaving the scene below it available for interaction. Click the Scene browser heading or press
`Shift+T` to collapse the tray into a small sidebar icon; click the icon to expand it. Drag its
right edge to resize every section together. The toggle tooltip shows your current shortcut;
you can change it in keybinding settings under **Scene browser**.
The existing Feature Tree and Bodies layout panes remain available alongside the Scene browser.

Click anywhere on the Feature tree row to collapse or expand just the operation history.

Default planes, operation history, and bodies use the same tree rows. A divider separates the
planes from operations, and keyboard navigation moves between both sections in one tree.

In user settings under **Modeling**, **Feature tree style** offers two choices: **HUD** (the
default) uses minimal branch guides and a faintly frosted tray; **Solid** uses standard tree
rows and a stronger frosted-glass Scene browser surface. This preference also applies to the Bodies section and updates
immediately.

The [Bodies section](/docs/zoo-design-studio/features/workspace/body-pane) beneath it lists the current
body-level results, so you can select and control finished geometry separately from its operation
history.

## Keyboard Navigation

Focus the tree to navigate rows with the up and down arrows. Use the right arrow to expand a
branch and the left arrow to collapse it. Type a label's beginning to move to a matching row.
Selection follows the model's existing single-selection behavior.

Press `F2` to enter a row's actions, `Escape` to return to the row, or `Shift+F10` to open its
context menu. These action shortcuts are registered commands and can be changed in the keybinding
settings.

## What You Can Do

- Inspect ordered model history and grouped operations.
- Select operations and jump to the corresponding KCL source.
- Double-click many supported operations to edit parameters.
- Use context menu actions such as `Edit`, `Delete`, `Translate`, `Rotate`, `Scale`, `Clone`, and
  `Set Appearance` when the operation type supports them.
- Export supported sketch operations to DXF from the context menu.

## What You Cannot Do

- Edit every operation from the tree. Some operation types are view-only or partially supported.
- Edit user-defined function or module operations from the tree. Edit those in code instead.
- Rely on tree-based editing for every sketch-on-face or offset-plane workflow. Some of those still
  require scene-based editing.

## Key Differences in This Area

- Tree items stay linked to command-bar edits and KCL source ranges.
- Editing coverage is intentionally partial, so some workflows remain code- or scene-driven.
