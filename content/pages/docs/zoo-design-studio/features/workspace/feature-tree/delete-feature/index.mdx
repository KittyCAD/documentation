---
title: Delete Feature
excerpt: Delete modeling features from history in Zoo Design Studio.
sidebarPosition: 1
---

Delete Feature removes a feature from the model history while preserving as much downstream intent as
possible.

To remove a body while keeping the features that created it, use
[Delete Body](/docs/zoo-design-studio/features/3d-design/parametric-modeling/transforms/delete-body). This adds a Delete operation to the history.
