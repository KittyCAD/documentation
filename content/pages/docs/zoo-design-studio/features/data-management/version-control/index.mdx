Zoo is currently developing a PLM-style version control system on top of its [Projects API](https://zoo.dev/docs/developer-tools/api/projects), but it is still under development, and [set to be rolled out toward the end of 2026](https://zoo.dev/roadmap).

However, since Zoo projects are just human-readable text files, version control systems like [Git](https://git-scm.com/) work great with them!

You should be able to use whatever version control system you prefer within a Zoo project's folder, and our systems like [Cloud Sync](/docs/zoo-design-studio/features/data-management/cloud-sync) will ignore the version control metadata and files from its syncing.

## What happens when you publish a version-controlled project

Publishing a Directory project to Aquarium moves the entire project folder into Personal Cloud
after a successful submission. Local version-control metadata moves with the folder, but it may surprise you to find that your project moved on your computer, so don't be alarmed the project is just in a new folder on your computer, which you can find under Libraries in your settings.
