Zoo is currently developing a PLM-style version control system on top of its [Projects API](https://zoo.dev/docs/developer-tools/api/projects), but it is still under development, and [set to be rolled out toward the end of 2026](https://zoo.dev/roadmap).

However, since Zoo projects are just human-readable text files, version control systems like [Git](https://git-scm.com/) work great with them!

Use Git or another version control system with projects in a Directory library. Cloud projects have no working folder on disk. Export or move a cloud project to a Directory library when you need local version-control tools.

## Publishing a Version-Controlled Project

Publishing a Directory project moves its editable content to Personal Cloud. Version-control metadata is not uploaded, and Personal Cloud does not maintain a local Git working copy. If an upload excludes files such as Git metadata or ignored files, Zoo keeps the original local folder and reports this after the cloud project is saved.
