Zoo is currently developing a PLM-style version control system on top of its [Projects API](https://zoo.dev/docs/developer-tools/api/projects), but it is still under development, and [set to be rolled out toward the end of 2026](https://zoo.dev/roadmap).

However, since Zoo projects are just human-readable text files, version control systems like [Git](https://git-scm.com/) work great with them!

Use Git or another version control system with projects in a Local library. Cloud projects have no working folder on disk. To use local version-control tools with a cloud project, [duplicate it into a Local library](/docs/zoo-design-studio/features/data-management/project-libraries#duplicate-projects).

## Publishing a version-controlled project

Publishing a Local project creates a cloud duplicate and keeps the original local folder, including its Git repository. Version-control metadata and files excluded by .gitignore are not uploaded. Later edits to the cloud project and the local original are independent.
