Use Fillet to create rounded transitions on edges or at face intersections. Fillets reduce stress concentrations, eliminate sharp edges, improve manufacturability, and communicate finished edge intent directly in the solid model.

## Options

### Selection
Select the edge or edges you want to round. You can pick multiple edges at once to apply the same radius to all of them.

### Radius
The size of the round, specified in your current units. Larger radii create gentler curves; smaller radii make tighter rounds. Make sure the radius isn't bigger than the space available (like trying to put a 10mm radius on a 5mm thick wall).

Common radius values by application:
- **0.5-2mm** - Standard edge breaks for sheet metal and machined parts
- **2-5mm** - Moderate fillets for comfortable hand-grip edges  
- **5mm+** - Large blends for high-stress areas or smooth aesthetic transitions

### Tag
Tag the new fillet surface if you need to reference it in later operations. A tag can only be assigned when a single edge is selected.

### Tangent Chain
Whether to continue the fillet along edges that are tangent to the selected edges. Defaults to true.

1. Choose **Fillet** <img src="/documentation-assets/docs/zoo-design-studio/features/3d-design/parametric-modeling/solid-modeling/modify-solids/fillet-icon.webp" alt="the fillet icon" /> from the toolbar or search for it in the [Command Bar](/docs/zoo-design-studio/features/workspace/command-bar).

    alt="the Fillet dialog with its arguments shown together"

2. Click **Selection** and select the edges to modify. You can also select edges before opening the dialog.

    width='500px'

3. Enter **Radius** directly in the dialog.

<img
    width='500px'
    src="/documentation-assets/docs/zoo-design-studio/features/3d-design/parametric-modeling/solid-modeling/modify-solids/fillet-radius.webp"
    alt="the Fillet dialog with a 0.5 mm radius"
/>

4. Leave **Tag** blank for this two-edge example. Leave **Tangent Chain** at its default or choose **On** to extend the fillet along tangent edges.

<img
    width='500px'
    src="/documentation-assets/docs/zoo-design-studio/features/3d-design/parametric-modeling/solid-modeling/modify-solids/fillet-options.webp"
    alt="the Fillet dialog with tangent chaining enabled"
/>

5. Click **Submit** to apply the fillet.

<img
    width='500px'
    src="/documentation-assets/docs/zoo-design-studio/features/3d-design/parametric-modeling/solid-modeling/modify-solids/fillet-result.webp"

6. To fillet only the selected edges, double-click the Fillet operation in the Feature Tree and set **Tangent Chain** to **Off**. Existing edge selections are read-only during editing.

<img
    width='500px'
    src="/documentation-assets/docs/zoo-design-studio/features/3d-design/parametric-modeling/solid-modeling/modify-solids/fillet-tangent-chain-options.webp"
    alt="editing the Fillet dialog with tangent chaining disabled"
/>

7. Click **Submit** to apply the change.

<img
    width='500px'
    src="/documentation-assets/docs/zoo-design-studio/features/3d-design/parametric-modeling/solid-modeling/modify-solids/fillet-results-no-chain.webp"

/>

Click **Cancel** or press Esc to discard the draft. If the dialog covers an edge, drag its header to move it.

## Are you interested in code?

Zoo Design Studio writes KCL behind the scenes. Here’s an example of a fillet in KCL:

```kcl
@settings(kclVersion = "3.0")

sketch001 = sketch(on = XY) {
  line1 = line(start = [var 0mm, var 0mm], end = [var 4.98mm, var 0mm])
  coincident([line1.start, ORIGIN])
  horizontal([line1.end, ORIGIN])
  arc1 = arc(start = [var 4.98mm, var 0mm], end = [var 4.98mm, var 3.56mm], center = [var 4.98mm, var 1.78mm])
  coincident([line1.end, arc1.start])
  tangent([line1, arc1])
  line2 = line(start = [var 4.98mm, var 3.56mm], end = [var 0mm, var 3.56mm])
  coincident([line2.start, arc1.end])
  vertical([line2.end, ORIGIN])
  line3 = line(start = [var 0mm, var 3.56mm], end = [var 0mm, var 0mm])
  coincident([line2.end, line3.start])
  coincident([line3.end, line1.start])
  horizontal(line2)
  tangent([line2, arc1])
}

hidden001 = hide(sketch001)
region001 = region(segments = [sketch001.line3, sketch001.line1])
extrude001 = extrude(region001, length = 5, tagEnd = $capEnd001)

fillet001 = fillet(
  extrude001,
  edges = [
    {
      sideFaces = [
        region001.tags.line1,
        extrude001.faces.capEnd001
      ]
    },
    {
      sideFaces = [
        region001.tags.line3,
        extrude001.faces.capEnd001
      ]
    }
  ],
  radius = 0.5,
)
```

Want to find out more about the `fillet` function? [Check it out](/docs/kcl-std/functions/std-solid-fillet) in our KCL docs.
