Use Chamfer to create beveled transitions on edges, providing edge breaks, fastener lead-ins, and simplified manufacturable transitions. Chamfers are easier to manufacture than fillets in some processes and provide functional benefits for assembly operations.

## Options

### Selection
Select the edge or edges to chamfer. Multiple edges can be selected to apply the same chamfer.

### Length
The primary chamfer distance measured from the edge along one face. This is your main setback dimension.

### Second Length
The distance along the other face. Use this with Length to create asymmetric chamfers where each side has a different setback. Leave blank for symmetric chamfers or when using angle mode.

### Angle
The chamfer angle in degrees from the first face. Use with Length to create distance-and-angle chamfers.

Typical angles:
- **45°** - Equal-leg chamfer (most common)
- **30° or 60°** - Asymmetric chamfers for specific requirements

### Tag  
Tag the chamfer surface if you need to reference it later.

### Tangent Chain
Whether to continue the chamfer along edges that are tangent to the selected edges. Defaults to true.

## Chamfer Types

**Equal Distance:** Specify only Length for a symmetric chamfer with equal legs.

**Distance-Distance:** Specify both Length and Second Length for asymmetric setbacks.

**Distance-Angle:** Specify Length and Angle for one fixed setback with the bevel at a specific angle.

## Steps

1. Choose **Chamfer** from the toolbar or search for it in the [Command Bar](/docs/zoo-design-studio/features/workspace/command-bar).
2. Click **Selection** in the Chamfer dialog and select the edges to modify. You can also select edges before opening the dialog.
3. Enter **Length** directly in the dialog.
4. For unequal setbacks, enter **Second length**. For a distance-and-angle chamfer, enter **Angle** instead. Leave both blank for equal setbacks.
5. Set an optional **Tag** if you need to reference the new surface, then click **Submit**.

Click **Cancel** or press Esc to discard the draft. If the dialog covers an edge, drag its header to move it.

## Are you interested in code?

Zoo Design Studio writes KCL behind the scenes. Here’s an example of a chamfer in KCL:

```kcl
@settings(kclVersion = "3.0")

sketch001 = sketch(on = XY) {
  line1 = line(start = [var 0mm, var 0mm], end = [var 4.98mm, var 0mm])
  coincident([line1.start, ORIGIN])
  horizontal([line1.end, ORIGIN])
  arc1 = arc(start = [var 4.98mm, var 0mm], end = [var 4.98mm, var 3.56mm], center = [var 4.98mm, var 1.78mm])
  coincident([line1.end, arc1.start])
  tangent([line1, arc1])
  line2 = line(start = [var 4.98mm, var 3.56mm], end = [var 0mm, var 3.56mm])
  coincident([line2.start, arc1.end])
  vertical([line2.end, ORIGIN])
  line3 = line(start = [var 0mm, var 3.56mm], end = [var 0mm, var 0mm])
  coincident([line2.end, line3.start])
  coincident([line3.end, line1.start])
  horizontal(line2)
  tangent([line2, arc1])
}

hidden001 = hide(sketch001)
region001 = region(segments = [sketch001.line3, sketch001.line1])
extrude001 = extrude(region001, length = 5, tagEnd = $capEnd001)

chamfer001 = chamfer(
  extrude001,
  edges = [
    {
      sideFaces = [
        region001.tags.line1,
        extrude001.faces.capEnd001
      ]
    },
    {
      sideFaces = [
        region001.tags.line3,
        extrude001.faces.capEnd001
      ]
    }
  ],
  length = 0.5,
)
```

Want to find out more about the `chamfer` function? [Check it out](/docs/kcl-std/functions/std-solid-chamfer) in our KCL docs.
