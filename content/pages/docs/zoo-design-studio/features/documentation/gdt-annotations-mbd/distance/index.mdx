Distance captures a dimensional tolerance for an edge length or for spacing between selected faces
and edges. Use it when a model-based definition needs the measured value to remain attached to the
3D geometry instead of living only in a separate drawing.

## From And To

Select a starting face or edge and an ending face or edge when the annotation should measure spacing
between two entities. `from` and `to` must be used together.

For two parallel planar faces, Distance measures perpendicular to the faces: the minimum distance
between their infinite supporting planes. Moving either face sideways does not change this value,
even when the face boundaries do not overlap. Other pairs of entities use their centers.
Coincident supporting planes cannot display a distance annotation.

## Edges

Select one or more edges when the annotation should display edge length. Edge selection cannot be
combined with `from` and `to`.

## Tolerance

Optionally set the acceptable distance variation in the current unit system. Skip this field to
show only the measured distance.

## Precision

Choose how many decimal places to display for the measured distance and tolerance.

## Frame Position

The label is centered by default, with its setback scaled to the model size. Set `[along, setback]`
to control its position: `along` moves it along the measurement and `setback` chooses the leader
extent perpendicular to the measurement. A negative setback places it on the opposite side.

## Frame Plane

Leave **Automatic** selected when measuring two parallel planar faces. Zoo chooses a display plane
that contains their common normal, including for rotated faces. The generated KCL omits `framePlane`
so the orientation is recalculated when the model changes.

An explicit display plane must contain the direction perpendicular to the measured faces. Its
origin does not change the measured distance. If the chosen plane is incompatible, choose Automatic
or another plane. Edge lengths and other entity pairs keep their existing display-plane behavior.

## Leader Scale

Adjust the visual scale of the distance arrows.

## Font Size

Set the model-space height of the annotation text.

## Are you interested in code?

Zoo Design Studio writes KCL behind the scenes. A Distance annotation uses `gdt::distance` with
either edge selections or a `from` / `to` pair.

```kcl
gdt::distance(
  edges = [lengthEdge],
  tolerance = 0.05mm,
  precision = 2,
  framePosition = [12mm, 8mm],
  framePlane = XZ,
)
```

Want to find out more about the `gdt::distance` function?
[Check it out](/docs/kcl-std/functions/std-gdt-distance) in our KCL docs.
