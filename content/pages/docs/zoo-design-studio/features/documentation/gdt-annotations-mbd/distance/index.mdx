Dimension adds a measured value to selected 3D geometry as part of model-based definition (MBD).
Select the geometry, then choose **Dimension** from the GD&T toolbar:

- Select one circle or a complete cylindrical face to annotate its diameter.
- Select one circular arc or a partial cylindrical face to annotate its radius.
- Select other edges to annotate their lengths, or select two faces or edges to annotate the distance
  between them. Selecting two circles or cylindrical faces measures their spacing.

The annotation stays attached to the geometry and updates when the model changes. Editing an
existing annotation preserves its measurement type.

## From And To

Select a starting face or edge and an ending face or edge when the annotation should measure spacing
between two entities. `from` and `to` must be used together.

## Edges

Select one or more edges when the annotation should display edge length. Edge selection cannot be
combined with `from` and `to`.

## Tolerance

Optionally set the acceptable dimensional variation in the current unit system. Leave tolerance
empty to display only the measured value.

## Precision

Choose how many decimal places to display for the measured value and tolerance.

## Frame Position

Place the dimension label relative to the selected geometry. For diameter and radius, the default
position places the label outward on the leader's side of the circle or arc, with spacing scaled to
the feature size and annotation font size. Set a position to override this placement.

## Frame Plane

Choose the display plane for the dimension annotation. Diameter and radius infer a standard plane
from the referenced circle or cylinder rim. Set a plane to override this choice.

## Leader Scale

Adjust the visual scale of the dimension arrows.

## Font Size

Set the model-space height of the annotation text.

## Are you interested in code?

Zoo Design Studio writes KCL behind the scenes. Diameter and radius annotations use
`gdt::diameter(target = ...)` and `gdt::radius(target = ...)`. Distance annotations continue to use
`gdt::distance` with either edge selections or a `from` / `to` pair.

```kcl
gdt::distance(
  edges = [lengthEdge],
  tolerance = 0.05mm,
  precision = 2,
  framePosition = [12mm, 8mm],
  framePlane = XZ,
)
```

Want to find out more about the `gdt::distance` function?
[Check it out](/docs/kcl-std/functions/std-gdt-distance) in our KCL docs.
